# Safety and legal boundaries

## What RecompRadar will not do

* **It never runs the analyzed file.** Files are opened read-only and parsed as data. There is no "run" button, and the
  Recompilation proof of concept only executes programs that the tests create themselves.
* **It does not circumvent protection.** Encrypted or signed containers (SELF, `~PSP`, PBP, PS4 SELF) are *recognised by
  their magic number* and reported as unsupported. There is no decryption, no key handling, no DRM bypass and no unpacking.
* **It does not ship third-party content.** The repository contains no commercial games, BIOS images, firmware, console
  keys or other protected assets. The files in `samples/` are synthetic and generated by this project.
* **It makes no promises about commercial software.** It does not claim that any commercial game can be compiled or
  started, and it does not output compatibility percentages.

## Your responsibility

Only analyze files you are legally entitled to analyze (your own builds, homebrew, open-source software, or files for
which you hold the necessary rights). Analysis results can contain file names, paths, hashes and symbol names from the
analyzed file; keep that in mind when sharing exported reports.

## Protection against hostile input

| Risk | Mitigation |
| --- | --- |
| Out-of-range reads from forged offsets | Every read goes through `BinaryView`, which checks `offset + size` against the file length with overflow-safe arithmetic |
| Huge allocations from forged counts or sizes | Table sizes are clamped to what really fits in the file, to configured limits and to a 64 MiB block cap |
| Integer overflow in address calculations | `ulong` arithmetic is checked or saturating wherever file values are added or multiplied |
| Infinite or very slow parsing | All loops are bounded by limits; cancellation is honoured between phases |
| Parser bugs | Unexpected exceptions become an `ELF.INTERNAL_ERROR` diagnostic; fuzz-style tests assert this never happens |
| Script injection through names | HTML export encodes all file-derived text and contains no scripts; control characters in names are replaced |
| Decompression bombs in the project database | Stored analyses are size-checked while unpacking |
| Malicious knowledge-base files | Size, count and pattern-length limits; no regular expressions |
| Third-party code | Plugins are registered in-process; no assemblies are loaded from disk automatically |

## Privacy

RecompRadar works fully offline. It sends nothing anywhere. Local data lives in
`%LOCALAPPDATA%\RecompRadar` (or the folder named by `RECOMPRADAR_DATA_DIR`): the project database, settings, the
knowledge folder and JSON-lines logs. Logs contain file names and hashes, never file contents.
