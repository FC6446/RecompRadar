# Sample files

All files in this folder are **synthetic**. They are generated by `tools/RecompRadar.SampleGenerator` from the
code in `tests/RecompRadar.TestSupport` and contain only ELF headers, tables, a few hand-written instructions and
made-up symbol names. They contain no code, data, firmware, keys or assets from any commercial product.

Files that mimic a console only copy *header characteristics* (CPU flags, addresses, naming patterns) so that the
analyzer's hints can be demonstrated. They are not real console executables and cannot run on one.

Open them in RecompRadar with drag and drop or **Open file**. Regenerate them with:

```
dotnet run --project tools/RecompRadar.SampleGenerator -- samples
```
